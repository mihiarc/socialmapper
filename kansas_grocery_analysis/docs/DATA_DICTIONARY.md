# Data Dictionary - Kansas Food Access Analysis

This document describes all input and output data files generated by the Kansas grocery access analysis.

## Input Data Files

### data/input/walmart_all.csv
Complete list of all Walmart-owned stores in Kansas region.

| Column | Type | Description |
|--------|------|-------------|
| name | string | Store name from OpenStreetMap |
| latitude | float | Latitude in decimal degrees (WGS84) |
| longitude | float | Longitude in decimal degrees (WGS84) |
| type | string | Always "walmart" for POI categorization |
| address | string | Formatted address string |
| city | string | City name |
| subtype | string | Store format: "supercenter", "neighborhood_market", "sams_club", "walmart" |

### data/input/walmart_supercenters.csv
Filtered list containing only Walmart Supercenters (full grocery stores).

| Column | Type | Description |
|--------|------|-------------|
| *Same as walmart_all.csv* | | Filtered to subtype="supercenter" only |

### data/input/small_grocers_all.csv
Complete list of non-Walmart grocery stores and food retailers.

| Column | Type | Description |
|--------|------|-------------|
| name | string | Store name from OpenStreetMap |
| latitude | float | Latitude in decimal degrees (WGS84) |
| longitude | float | Longitude in decimal degrees (WGS84) |
| type | string | Always "small_grocer" for POI categorization |
| address | string | Formatted address string |
| city | string | City name |
| subtype | string | Store category: "convenience_store", "dollar_store", "grocery", "specialty_food", etc. |

### data/input/small_grocers_{subtype}.csv
Filtered lists by store subtype (e.g., small_grocers_dollar_store.csv).

| Column | Type | Description |
|--------|------|-------------|
| *Same as small_grocers_all.csv* | | Filtered to specific subtype |

## Analysis Output Files

### data/output/walmart_access/

#### census_data.csv
Demographics of census block groups within 30-minute drive of Walmart.

| Column | Type | Description |
|--------|------|-------------|
| GEOID | string | Census block group identifier (12 digits) |
| poi_id | integer | Associated Walmart store ID |
| travel_distance_km | float | Network distance to nearest Walmart |
| travel_time_min | float | Travel time to nearest Walmart |
| avg_travel_speed_kmh | float | Average speed on route |
| B01003_001E | integer | Total population |
| B19013_001E | float | Median household income |
| B17001_002E | integer | Population below poverty level |
| B08201_002E | integer | Households with no vehicle |
| B01001_020E-025E | integer | Male population 65+ by age group |
| B01001_044E-049E | integer | Female population 65+ by age group |

#### isochrones.geoparquet
Geographic boundaries of 30-minute drive areas around Walmarts.

| Column | Type | Description |
|--------|------|-------------|
| poi_id | integer | Walmart store identifier |
| poi_name | string | Walmart store name |
| travel_time | integer | Travel time in minutes (30) |
| geometry | geometry | Polygon representing accessible area |

### data/output/small_grocer_access/

#### census_data.csv

| Column | Type | Description |
|--------|------|-------------|
| *Same structure as walmart_access/census_data.csv* | | For 8-minute drive areas |

#### isochrones.geoparquet
Geographic boundaries of 5km areas around small grocers.

| Column | Type | Description |
|--------|------|-------------|
| *Same structure as walmart_access/isochrones.geoparquet* | | For 8-minute drive areas |

### data/output/food_desert_classification.csv
Final classification of all Kansas census block groups.

| Column | Type | Description |
|--------|------|-------------|
| GEOID | string | Census block group identifier |
| total_population | integer | Total population from census |
| county | string | County name |
| tract | string | Census tract identifier |
| classification | string | "food_desert", "vulnerable", or "well_served" |
| nearest_walmart_km | float | Distance to nearest Walmart (if available) |
| nearest_grocer_km | float | Distance to nearest small grocer (if available) |
| pct_poverty | float | Percentage below poverty line |
| pct_no_vehicle | float | Percentage of households without vehicle |
| pct_elderly | float | Percentage aged 65 and older |

## Cache Files

Cached OpenStreetMap road networks for faster isochrone generation.
- Named by geographic hash
- Compressed pickle format
- Automatically managed by SocialMapper

| Column | Type | Description |

| timestamp | datetime | When geocoded |

## Data Quality Notes

1. **Missing Values**
   - Census data may have null values for suppressed data
   - Store addresses may be incomplete in rural areas
   - Use -999 for missing numeric values, empty string for text

2. **Coordinate Precision**
   - Coordinates stored to 6 decimal places
   - Approximately 0.1 meter precision

3. **Time Stamps**
   - All times in UTC
   - ISO 8601 format (YYYY-MM-DD HH:MM:SS)

4. **Character Encoding**
   - All text files use UTF-8 encoding
   - Special characters preserved in store names
